# NeverForest

![Версия](https://img.shields.io/badge/version-1.1.0-a7c080) ![Obsidian](https://img.shields.io/badge/Obsidian-1.5%2B-a7c080) ![Лицензия](https://img.shields.io/badge/license-MIT-a7c080)

Тема Obsidian в палитре **Everforest** (medium): тёплые зелёно-кремовые поверхности, низкий контраст, мягкие акценты, компактное дерево файлов с цветными папками и подсветкой служебных заметок.

Тема написана с нуля: это не форк и не надстройка над другой темой. Сама тема состоит из двух файлов — `theme.css` и `manifest.json`, сторонние сниппеты не требуются.

| Параметр | Значение |
| :--- | :--- |
| Палитра | [Everforest](https://github.com/sainnhe/everforest) (medium, sainnhe) |
| Режимы | тёмный и светлый |
| Версия | 1.1.0 |
| Минимальная версия Obsidian | 1.5.0 |
| Автор | Nurs |
| Файлы | `manifest.json`, `theme.css` (≈79 КБ, ~2040 строк) |
| Зависимости | нет |
| Необязательно | плагин **Style Settings** — только для переключателей |

## Установка

1. Скопируй папку `NeverForest` в хранилище:

   ```text
   <vault>/.obsidian/themes/NeverForest/
   ├── manifest.json
   └── theme.css
   ```

2. Полностью закрой Obsidian — включая иконку в системном трее. Темы читаются при старте приложения, поэтому свёрнутое окно не подхватит новую папку.
3. Запусти Obsidian и открой **Settings → Appearance → Themes**.
4. Выбери **NeverForest** в списке.

Текущая тема хранится в `.obsidian/appearance.json`:

```json
{
  "cssTheme": "NeverForest"
}
```

> **Имя папки = идентификатор темы.** Obsidian использует имя папки как ID темы, а `name` в `manifest.json` — как подпись в списке. Они должны совпадать: `NeverForest` и `NeverForest`. Имя состоит из одного слова: так Obsidian стабильнее сопоставляет папку с темой, и в списке не появляется двойников.

### Обновление темы

Obsidian не перечитывает `theme.css` на лету. После правок:

- переключись на другую тему и обратно в **Appearance → Themes**, или
- перезапусти Obsidian.

Папку `NeverForest` при этом удалять не нужно.

## Почему NeverForest

Название собрано из двух частей: **N** — первая буква ника автора (**N**urs), а **EverForest** — палитра, на которой построена тема. **N + EverForest = NeverForest**.

Одна буква превратила «вечнозелёный лес» в «лес, которого нет» — этот каламбур и остался названием.

Имя пишется одним словом: Obsidian использует имя папки как идентификатор темы, и слитное имя избавляет от двойников в списке.

Тема изначально задумывалась как самостоятельная, а не как набор переключателей поверх другой темы: в ней нет форков, а всё оформление выводится из собственных токенов.

## Как тема устроена

Весь внешний вид выводится из переменных в первых трёх секциях `theme.css`:

- **секция 1** — палитра Everforest, акцент, радиусы, шрифты, размеры;
- **секция 2** — значения для тёмной схемы (`.theme-dark`);
- **секция 3** — значения для светлой схемы (`.theme-light`).

Дальше идут секции, которые используют эти переменные. Поэтому палитру можно поменять в одном месте, не трогая остальные ~2000 строк.

### Исторические имена `--nord*`

Токены называются `--nord0` … `--nord15`, хотя тема построена на Everforest. Это сделано намеренно: остальной stylesheet написан против этих имён, и переименование потребовало бы правок по всему файлу. В секции 1 им соответствуют цвета Everforest:

```css
--nord0: #2d353b;   /* bg0  */
--nord4: #d3c6aa;   /* fg   */
--nord8: #7fbbb3;   /* blue */
```

Не переименовывай их без необходимости — сломаются цветные папки, подсветка файлов и чекбоксы.

Ключевые переменные:

| Переменная | Назначение |
| :--- | :--- |
| `--nord0` … `--nord15` | 16 токенов палитры |
| `--nc-accent`, `--nc-accent-hover` | ссылки, фокус, выделение, теги, чекбоксы |
| `--nc-bg-deep`, `--nc-bg-side`, `--nc-bg-panel`, `--nc-bg-editor` | поверхности интерфейса |
| `--nc-line`, `--nc-line-soft`, `--nc-guide` | границы и линии отступов |
| `--nc-file-agents`, `--nc-file-readme`, `--nc-file-moc` | цвета подсветки служебных заметок |
| `--nc-folder-fg-dark`, `--nc-folder-fg-light` | текст на цветных строках папок |
| `--nc-radius-s`, `--nc-radius-m`, `--nc-radius-l` | радиусы 4 / 8 / 12 px |

## Дерево файлов

### Цветные папки верхнего уровня

Каждая папка первого уровня получает свой цвет. Девять оттенков идут по кругу (`nth-child(9n+1)` … `9n+9`):

| Порядок | Токен | Тёмная | Светлая | Оттенок |
| ---: | :--- | :--- | :--- | :--- |
| 1 | `--nord11` | `#e67e80` | `#d94a4a` | красный |
| 2 | `--nord12` | `#e69875` | `#d9691f` | оранжевый |
| 3 | `--nord13` | `#dbbc7f` | `#a87c00` | жёлтый |
| 4 | `--nord14` | `#a7c080` | `#6f8100` | зелёный |
| 5 | `--nord7` | `#83c092` | `#2f8f6a` | aqua |
| 6 | `--nord8` | `#7fbbb3` | `#2f7fae` | синий |
| 7 | `--nord9` | `#83c092` | `#2f8f6a` | aqua (повтор) |
| 8 | `--nord15` | `#d699b6` | `#b4529a` | сиреневый |
| 9 | `--nord10` | `#7fbbb3` | `#2f7fae` | синий (повтор) |

В Everforest меньше акцентов, чем в Nord, поэтому пары 5/7 и 6/9 совпадают. Это нормально: оттенки всё равно чередуются, а строки различаются положением.

Порядок зависит от сортировки папок в проводнике (по имени). В тёмной схеме строка заливается цветом, а текст на ней тёмный (`#2d353b`) — так контраст выше для всех девяти оттенков.

### Светлая схема: пастельные строки

В светлой палитре акценты глубокие (лесной зелёный, олива, охра, сланцевый синий). Если залить строку таким цветом, получится тёмный текст на тёмной полосе. Поэтому в светлой схеме используется другой приём:

- строка заливается **смесью 16 % цвета папки** с фоном сайдбара (при наведении — 26 %);
- подпись окрашивается в **смесь 72 % цвета папки** с почти чёрным `#1b201f`;
- яркость строки при наведении не повышается (`filter: none`), меняется только процент смеси.

В тёмной схеме строки остаются полностью залитыми.

### Линии отступов

- Цвет линии наследует только **первый** уровень вложенности папки — тонкий оттенок её цвета.
- Всё, что глубже, использует нейтральный `--nc-guide`.

Это исправление проблемы, которая была в теме PLN: там цвет линии задавался на папке и наследовался на все уровни, а каждому `.tree-item-children` ставился `border-radius`. В результате при раскрытии появлялись несколько параллельных цветных линий и «закруглённый узор».

### Стабильные строки

В теме сознательно **нет горизонтальных отступов** у строк дерева. Виртуализированный список Obsidian после раскрытия/сворачивания переписывает `margin-inline-start` и `padding-inline-start` у `.tree-item-self` с `!important`, поэтому собственный горизонтальный отступ был бы отброшен, а строка прыгала бы вбок.

Что сделано вместо этого:

- `padding-inline: var(--size-4-3, 12px)` — родной отступ Obsidian;
- `scrollbar-gutter: stable` — полоса прокрутки не меняет ширину строк;
- вертикальные отступы (`margin-block`) — их Obsidian не трогает.

## Служебные заметки

Файлы `AGENTS.md`, `README.md` и все MOC-заметки выделяются в дереве: **цветной жирный заголовок + вертикальная полоса 3 px** слева. Фон не заливается.

| Файл | Цвет (тёмная / светлая) | Переменная |
| :--- | :--- | :--- |
| `AGENTS.md` | `#d699b6` / `#a8548f` | `--nc-file-agents` |
| `README.md` | `#7fbbb3` / `#2e7fa8` | `--nc-file-readme` |
| MOC-заметки | `#dbbc7f` / `#9a7400` | `--nc-file-moc` |

Полоса рисуется псевдоэлементом `::after`, её ширина и отступ настраиваются:

```css
body {
    --nc-file-bar: 3px;        /* толщина полосы */
    --nc-file-bar-offset: 18px; /* отступ от левого края */
}
```

Подсветка не гаснет при наведении: правило для `:hover` отдельно возвращает нужный цвет.

### Какие имена считаются MOC

Шаблон ищет `MOC` в разных позициях имени, регистр не важен:

| Позиция | Примеры |
| :--- | :--- |
| суффикс через дефис, подчёркивание или пробел | `20-Areas-MOC.md`, `MOC_Name.md`, `Topic MOC.md` |
| префикс | `MOC-Template.md`, `MOC Name.md`, `MOC_Index.md` |
| внутри пути | `.../MOC-Health.md`, `.../MOC Health.md` |
| отдельный файл | `MOC.md` |
| в середине имени | `00-MOC-Health.md`, `30_resources_moc.md` |

Этого набора достаточно для текущего хранилища: `20-Areas-MOC`, `00-MOC-*`, `30-resources-moc`, `MOC-Template`, `MOC.md`. Если появится новая схема имени, допиши селектор в секции 7.

## Чекбоксы и статусы задач

Базовая логика — из темы **Tokyo Night**: неотмеченный чекбокс это кольцо, отмеченный — залитый круг с галочкой. Для нестандартных статусов вместо галочки показывается маленькая цветная пиктограмма.

| Свойство | Значение |
| :--- | :--- |
| Форма | круг (`--checkbox-radius: 999px`) |
| Рамка | `var(--text-faint)` — видна в обеих схемах |
| Заливка | `var(--nc-accent)` (лесной зелёный) |
| Галочка | `var(--text-on-accent)` |
| Размер | 16 px |

### Поддерживаемые статусы

| Синтаксис | Значение | Цвет значка |
| :--- | :--- | :--- |
| `- [ ]` | обычная задача | кольцо |
| `- [x]` | выполнена | зелёный акцент + галочка, текст зачёркнут |
| `- [/]` | в процессе | жёлтый |
| `- [>]` | перенесена | розовый |
| `- [<]` | запланирована | синий |
| `- [!]` | важная | оранжевый |
| `- [?]` | вопрос | розовый |
| `- [*]` | звезда | жёлтый |
| `- [-]` | отменена | приглушённый, текст зачёркнут |
| `- [b]` | закладка | синий |
| `- [n]` | заметка | бирюзовый |
| `- [i]` | идея | бирюзовый |
| `- [I]` | информация | оранжевый |
| `- [p]` | плюс / аргумент «за» | зелёный |
| `- [c]` | минус / аргумент «против» | красный |
| `- [l]` | место | красный |
| `- [S]` | сумма / деньги | зелёный |
| `- [u]` | вверх | зелёный |
| `- [d]` | вниз | красный |
| `- ["]` | цитата | фиолетовый |

Значки — это SVG-маски из MIT-темы Tokyo Night, перекрашенные в токены `var(--color-*)`. Рисунок одинаковый, цвета берутся из палитры Everforest: приглушённый зелёный, охра, тёплый красный.

> **Важно:** цветные пиктограммы видны в **режиме чтения**. В Live Preview Obsidian не отдаёт `data-task` на сам `input`, поэтому там остаётся обычный чекбокс. Это ограничение не темы, а поведения Obsidian; в оригинальной Tokyo Night так же.

## Style Settings

Если установлен плагин **Style Settings**, в **Settings → Style Settings → NeverForest** появятся пять переключателей. Без плагина они просто ничего не делают — тема работает и так.

| Переключатель | CSS-класс на `body` | Что меняет |
| :--- | :--- | :--- |
| Plain top-level folders | `nc-plain-folders` | убирает цветные строки папок и цветные линии |
| Neutral indentation guides | `nc-neutral-guides` | делает все линии отступов серыми |
| Disable file highlights | `nc-no-file-highlights` | отключает подсветку `AGENTS.md` / `README.md` / MOC |
| Compact file tree | `nc-compact-tree` | уменьшает вертикальные отступы строк |
| Plain task checkboxes | `nc-plain-checkboxes` | убирает пиктограммы статусов, оставляет кружки |

Класс добавляется на `<body>`. В CSS-сниппете это можно сделать вручную:

```css
body.nc-plain-folders .nav-files-container > div > .nav-folder > .nav-folder-title {
    background-color: transparent !important;
}
```

## Оформление интерфейса

- **Окно:** заголовок, ribbon, статус-бар и боковые панели сведены к одной системе поверхностей и границ.
- **Вкладки:** компактные, активная вкладка выделяется фоном и акцентом, без «таблеток».
- **Поиск и палитра команд:** скруглённые панели, мягкая тень, подсветка выбранного результата акцентом.
- **Редактор и чтение:** ширина строки `44rem`, межстрочный интервал `1.65`, чуть плотнее списки.
- **Заголовки:** `h2` получает тонкую линию снизу, цвета заголовков заданы явно и не зависят от версии Obsidian.
- **Код:** отдельный фон, рамка, радиус 8 px; моноширинный шрифт — Cascadia Code с запасными вариантами.
- **Таблицы:** скруглённая рамка, полосатая чётность строк, подсветка строки при наведении.
- **Цитаты:** полоса акцента слева и мягкий фон.
- **Вставки (embeds):** рамка с акцентной полосой слева.
- **Callout-блоки:** цвет берётся из типа блока, слева полоса 3 px, внутри — мягкая заливка 8 %. Кроме встроенных типов тема объявляет три своих — см. ниже.
- **Свойства (frontmatter):** отдельная панель с рамкой и радиусом.
- **Граф и Canvas:** цвета узлов и связей приведены к палитре.
- **Адаптивность:** при ширине меньше 800 px уменьшаются поля, таблицы и вкладки.
- **Анимации:** при `prefers-reduced-motion: reduce` переходы отключаются.

### Свои типы callout

Встроенные типы Obsidian задаются триплетами в секциях 2 и 3, а общее оформление в секции 10 читает `--callout-color`. Поэтому новый тип — это только цвет и иконка:

| Синтаксис | Смысл | Иконка | Тёмная / светлая |
| :--- | :--- | :--- | :--- |
| `> [!forest]` | итог, вывод, «тема закрыта» | `lucide-trees` | `#83c092` / `#2f8f6a` |
| `> [!guide]` | пошаговая инструкция | `lucide-compass` | `#7fbbb3` / `#2f7fae` |
| `> [!source]` | источник, библиография | `lucide-book-marked` | `#d699b6` / `#b4529a` |

```markdown
> [!forest] Итог
> Тема собрана и выбрана в Appearance.

> [!guide]- Свернуть инструкцию
> Шаг 1. Шаг 2. Шаг 3.
```

Сворачивание работает как у встроенных: `-` закрывает блок, `+` открывает. Редактор свои типы не подсказывает, а иконка должна существовать в Lucide — иначе слева останется пустое место.

## Кастомизация

### Сменить акцент

Акцент управляет ссылками, фокусом, выделением, тегами и чекбоксами:

```css
body {
    --nc-accent: #d699b6;
    --nc-accent-hover: #e0aec6;
}
```

Для разных схем:

```css
body.theme-dark  { --nc-accent: #a7c080; }
body.theme-light { --nc-accent: #8da101; }
```

### Сменить цвет одной папки

Цвета заданы по порядку, а не по имени. Чтобы закрепить цвет за конкретной папкой, перекрой переменную по `data-path`:

```css
.nav-files-container > div > .nav-folder[data-path="10-Projects"] {
    --nc-hue: var(--nord14);
    --nc-hue-fg: var(--nord0);
}
```

В светлой схеме не забудь про смешивание: цвет строки и подписи считается через `color-mix`, поэтому `--nc-hue-fg` там переопределяется отдельным правилом `body.theme-light`.

### Подсветить другие файлы

Скопируй блок для `README.md` в секции 7 и замени селектор:

```css
body:not(.nc-no-file-highlights) .nav-file-title[data-path$="DAILY.md" i] {
    --nc-file: var(--nord14);
    position: relative;
    color: var(--nc-file);
    font-weight: 700;
}
```

Не забудь продублировать `::after` и `:hover`, иначе полоса не появится или цвет мигнёт при наведении.

### Добавить свой тип callout

Нужны два правила в секции 10 и два триплета — в секциях 2 и 3:

```css
body.theme-dark  { --callout-idea: 219, 188, 127; }
body.theme-light { --callout-idea: 168, 124, 0; }

.callout[data-callout="idea"] {
    --callout-color: var(--callout-idea);
    --callout-icon: lucide-lightbulb;
}
```

Цвет только триплетом `R, G, B`: общие правила подставляют его внутрь `rgb()` и `rgba()`, поэтому hex-значение сломает вид. Иконка — имя из Lucide, например `lucide-lightbulb`; в теме уже есть `forest`, `guide` и `source` как образцы.

### Где менять

| Что | Где |
| :--- | :--- |
| Палитра, шрифты, радиусы | секция 1, `body` |
| Тёмные поверхности | секция 2, `.theme-dark` |
| Светлые поверхности и акценты | секция 3, `.theme-light` |
| Цвета папок | секция 7, `nth-child(9n+1…)` |
| Пастельные строки в светлой схеме | секция 7, `body.theme-light …` |
| Служебные заметки | секция 7, блок `Special notes` |
| Чекбоксы | секция 16 |
| Свои типы callout | секция 10, блок `Custom callout types`; цвета — секции 2 и 3 |

Правки лучше держать в конце файла или в отдельном сниппете: так проще обновлять тему.

## Устранение неполадок

| Симптом | Причина и решение |
| :--- | :--- |
| Темы нет в списке Appearance | Obsidian читает папки тем только при старте. Закрой приложение полностью, включая трей, и запусти снова. |
| Правки в `theme.css` не видны | Файл не перечитывается на лету. Переключи тему туда-обратно или перезапусти Obsidian. |
| В списке две похожие темы | Имя папки и `name` в `manifest.json` разошлись. Приведи их к одному виду. |
| Нет цветных строк папок | Включён `nc-plain-folders` в Style Settings или сниппете. |
| В светлой схеме папки почти белые | Так и задумано: строка — смесь 16 % цвета папки с фоном. Увеличь процент в секции 7, если нужен более насыщенный вид. |
| Нет подсветки `AGENTS.md` / `README.md` | Включён `nc-no-file-highlights`; либо файл переименован и не совпадает с шаблоном. |
| У задач одинаковые галочки | Включён `nc-plain-checkboxes`; либо открыт Live Preview, где статусы не передаются. |
| Строки дерева «прыгают» | В тему добавлен горизонтальный `margin` или `padding` для `.tree-item-self` / `.nav-file-title`. Убери его: Obsidian перезаписывает эти свойства. |
| Цветные линии идут на всех уровнях | Кто-то вернул наследование `--nav-indentation-guide-color` на папку. Цвет должен задаваться только на `.tree-item-children` первого уровня. |
| MOC не подсвечивается | Имя не попадает ни под один шаблон из таблицы выше. Добавь селектор в секцию 7. |
| Свой callout выглядит как обычный | Тип не совпал: в CSS должно быть `[data-callout="имя"]` в нижнем регистре, а цвет — триплет `R, G, B`. |

## Ограничения

- Тема рассчитана на **десктопный Obsidian 1.5+**; мобильная вёрстка отдельно не настраивалась.
- Цветные пиктограммы статусов работают в режиме чтения, не в Live Preview (поведение Obsidian).
- Шаблон MOC основан на имени файла. Заметка с MOC-содержимым, но без `MOC` в имени, не подсветится.
- Цвета папок привязаны к порядку сортировки, а не к смыслу папки. Для закрепления цвета используй `data-path` (см. «Кастомизация»).
- В Everforest меньше акцентов, чем в Nord, поэтому некоторые папки получают одинаковый оттенок (5/7 и 6/9).
- Свои типы callout (`forest`, `guide`, `source`) редактор не подсказывает: имя нужно помнить. Иконка берётся из Lucide, свои SVG не поддерживаются.
- Тема не включает сниппеты: всё оформление живёт в `theme.css`.
- Сторонние плагины, которые полностью перестраивают дерево файлов, могут перекрывать стили папок.
