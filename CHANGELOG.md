# Изменения

Формат — [Keep a Changelog](https://keepachangelog.com/ru/1.1.0/), версии по [SemVer](https://semver.org/lang/ru/).

## [1.1.0] — 2026-11-17

### Добавлено

- Свои типы callout: `forest` (итог), `guide` (инструкция), `source` (источник) — цвет в обеих схемах, иконки Lucide.
- Раздел «Свои типы callout» в README и рецепт добавления нового типа.

### Изменено

- `manifest.json`: добавлен `authorUrl`.

## [1.0.0] — 2026-11-14

### Добавлено

- Первый выпуск: 16 секций CSS, тёмная и светлая схемы Everforest medium.
- Цветные строки папок верхнего уровня, тонирование в светлой схеме, линии отступов только на первом уровне.
- Подсветка `AGENTS.md`, `README.md` и MOC-заметок.
- Чекбоксы в стиле Tokyo Night с 18 дополнительными статусами.
- Пять переключателей Style Settings.
- README темы: установка, палитра, кастомизация, устранение неполадок.
